Machine Learning Project

Customer Churn Prediction System

Interactive Video Walkthrough
Pipeline Demo • Full HD

▶ Live demonstration showing feature distribution analysis, real-time risk scoring slider, and Streamlit inference pipeline.

System Overview

Customer attrition is a major revenue drain for subscription services. This end-to-end Machine Learning pipeline identifies high-risk customers before churn occurs, allowing data-driven retention campaigns.

Key Architecture & Methodology

  • Data Wrangling: Cleaned 7,000+ subscriber records, handled missing inputs, and applied one-hot encoding for categorical customer attributes.
  • Feature Importance: Identified contract duration, monthly charges, and tenure as primary churn drivers using Random Forest feature weights.
  • Hyperparameter Tuning: Optimized decision depth, estimator count, and regularization with GridSearchCV for maximum AUC-ROC curve performance.
  • Interactive UI: Built a lightweight Streamlit dashboard enabling business teams to input customer profiles and receive instant attrition risk assessments.

0.91 AUC-ROC Score
